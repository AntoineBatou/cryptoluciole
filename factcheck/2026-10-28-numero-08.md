F1. **Marge « mode standard » : affirmation inversée.**
   - La fiche dit qu'en mode standard (par défaut) « le put vendu est traité comme s'il n'était pas couvert », et que seul le mode portefeuille retient la perte maximale.
   - La doc Derive (aide « Standard margin », version V2/legacy) dit : « for each position in isolation, **except for option spreads with the same expiry, whose margin is offset** ». Pour un spread de puts de même échéance, le mode standard plafonne déjà la marge à la perte maximale (≈ 200 $).
   - Le comparatif SM/PM de Derive indique que le mode portefeuille n'apporte rien sur un spread long simple, mais sert aux livres plus complexes. Pour un spread de 300 $ de largeur vendu, l'exigence standard est de 300 $.

   - Proposé : « Dans le mode standard, chaque position est évaluée isolément, sauf les spreads de même échéance, dont la marge est compensée : tu bloques environ 200 $. Le mode portefeuille est conçu pour les livres plus complexes. » Réserve : je n'ai pas pu ouvrir les docs V3, ces pages datent d'avant la V3 (❓).
