# Calibrage du vérificateur

But : savoir si la boucle rédacteur → vérificateur filtre vraiment ce que Marc corrige. Une ligne
par section montrée à Marc. Tenu par la session principale, juste après la relecture de Marc.
Lu par le vérificateur au démarrage.

**Comment remplir.** Note = celle du vérificateur avant la relecture de Marc. Tests = questions-tests
réussies sur 8 (à partir du numéro 11). Verdict de Marc : *validé tel quel*, *retouché* (coupes ou
reformulations locales), *refusé* (à refaire). Coupes prévues = combien des 3 coupes prédites par le
vérificateur Marc a réellement faites.

**Comment lire.** Si une rubrique cumule les « 8+ puis refusé », c'est la grille qui est à revoir
sur cette rubrique, pas le rédacteur. Si les coupes prévues restent à 0 ou 1 sur 3, le vérificateur
ne connaît pas encore les réflexes de Marc sur ce type de texte.
